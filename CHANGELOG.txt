## 1.0.4 (2026-08-29)

- Added a Pull Mode toggle for switching between pull assignments and floor-wide marker and CC editing.
- Split mob CC Marks from live player marks.
- Added named player-mark loadouts with raid and guild autocomplete plus explicit enable and disable controls.
- Fixed pending player-mark rows disappearing and compacted the loadout delete dialog.

- Preserved active Live Sessions across UI reloads.
- Synchronized floor-wide NPC marks when joining and editing Live Sessions.

## 1.0.2 (2026-08-27)

- Fixed release packages omitting the load-on-demand UI addon.

## 1.0.1 (2026-08-27)

- Added Battle for Mount Hyjal wave planning with direct marker and CC assignment controls.
- Added pull-mob portraits, saved positioning and clearer Pull > Floor > Global assignment ordering to the Active Pull tracker.
- Displayed Hyjal progress within each boss segment while preserving global wave progression internally.
- Added separate Clear Marks and Clear CC actions to the Hyjal wave card.
- Fixed Hyjal opening in pull mode instead of wave mode.
- Fixed wave markers and CC assignments not appearing or clearing correctly.
- Fixed CC assignments moving to another marker when editing a wave.
- Fixed CC menus resolving the wrong pull when a route contains multiple pulls.
- Fixed lower-priority CC assignments merging onto NPCs that are immune to that crowd control.
- Fixed stale or incompatible global assignees appearing in the Active Pull tracker.

## 1.0.0 (2026-08-27)

- Added interactive raid maps and route planning for Gruul's Lair, Magtheridon's Lair,
  Serpentshrine Cavern, The Eye, Battle for Mount Hyjal and Black Temple.
- Added floor-scoped pulls and Auto Marks with configurable mouseover modifiers.
- Added pull-specific and raid-wide crowd-control assignments with class-colored assignees.
- Added the Active Pull tracker with merged pull and global assignments.
- Added live sharing for presets, pulls, raid progress, assignments, notes and drawings.
- Added clickable chat links for sharing and importing presets with raid members.
- Added export/import support and load-on-demand UI startup.
- Added compatibility and validation coverage for TBC Anniversary interfaces 20505 and 20506.
- Added a local 8-group raid roster with guild autocomplete and current-raid loading.
- Added preset-wide player marks with export, import, Live Session sync, and automatic application.
- Added optional class-compatible CC roles to global player marks.
- Added Pull > floor All Mark > global player mark precedence in the Active Pull tracker.
- Merged lower-priority CC roles into higher-priority marker rows when their own CC is unset.
- Scoped NPC marker and CC defaults to individual raid floors with legacy preset migration.
- Added per-NPC, active-pull and current-floor marker clearing with matching CC cleanup.
- Preserved Auto Marks scrolling during marker and CC edits and avoided unnecessary map-blip rebuilds.
- Fixed stale Active Pull assignments after pull, floor and raid changes.
- Fixed Quick Mark binding cleanup to avoid protected-action errors during combat.
